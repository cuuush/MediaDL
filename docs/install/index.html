For iPhone & iPad

Two installs.
Then you're ready.

MediaDL uses the free Scriptable app to download photos and videos from Instagram and X. Install both below.

  1. Install Scriptable

    Download the free app from the App Store. This is required for both Instagram and X. You don't need to open it or add a script.

    Get Scriptable from the App Store

    Already installed? Go straight to step 2.

  2. Add MediaDL to Shortcuts

    Tap the button below, then choose Add Shortcut. If you already have MediaDL, replace the older version when prompted.

    Add MediaDL

    If your browser downloads a file, tap MediaDL.shortcut in Downloads or Files to open it in Shortcuts. Get Shortcuts if needed.

  3. Share a post

    Open a post in Instagram or X, tap Share, and choose MediaDL. Allow the requested network and Photos access. Saved files appear in the Instagram or X album in Photos.

    Instagram may prompt you to sign in through Scriptable; sign in, close the login page, and share the post again. X does not require a login. For X videos, choose a resolution and bitrate before downloading when multiple qualities are available.

“A required app is missing”?

Install Scriptable using step 1, then run MediaDL again. You do not need to reinstall the shortcut. If Scriptable is installed, make sure you are running on your iPhone or iPad; this shortcut isn't a Mac downloader.
