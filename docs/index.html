Install MediaDLRelease notes

Start with Scriptable

Install Scriptable from the App Store, then add MediaDL to Shortcuts. That's it. Our step-by-step install page has both links.

What can I save?

Instagram posts, reels, stories, carousels, and profile pictures. Public X posts with photos, videos, and animated GIFs; GIFs save as MP4. Instagram requires sign-in, and some restricted posts may be unavailable.

MediaDL is a fork of plbstl/MediaDL with X support and Instagram fixes. Source code · CC BY-NC-SA 4.0
