MediaDL

Save photos and videos from Instagram & X.

  1. 1 Install Scriptable

    Free app required for downloads. Skip if installed.

    Get Scriptable

  2. 2 Add MediaDL

    Open the preview and tap Add Shortcut.

    Add MediaDL

Then share a post and choose MediaDL.

Need help?

Use an iPhone or iPad with Shortcuts. Instagram may ask you to sign in through Scriptable, then share the post again.

If a required app is missing, install Scriptable and run MediaDL again. You don't need to reinstall the shortcut or open Scriptable beforehand.
